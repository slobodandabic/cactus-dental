# Cactus Wren Dental (concept site)

Single-page website for a fictional family dental office in Phoenix, AZ.
Built as a portfolio project by [Slobodan Dabic](https://sdabic.com).

**Live:** https://cactus-dental-beta.vercel.app

- Plain HTML, CSS and JavaScript, no build step
- Online booking in 4 steps with real open/closed days and time slots (demo)
- Instant insurance checker and a membership plan for patients without insurance
- Live "open now" status and today's hours, based on Phoenix time
- Team section, reviews, FAQ, responsive layout with a sticky booking bar on mobile
- Images converted to WebP (about 250 KB in total)

Cactus Wren Dental, its team members, reviews and prices are fictional. Phone numbers use the fictional 555-01xx range. Photos are stock images; logos and names on uniforms were blurred.
